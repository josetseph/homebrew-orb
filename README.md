# Homebrew tap for Orb

```sh
brew install --cask josetseph/orb/orb
```

Installs the latest [Orb](https://github.com/josetseph/Orb) desktop release for Apple Silicon or Intel Macs (macOS 12+).
Orb is not notarized, so the cask clears the quarantine flag after installing; you won't need to run `xattr` yourself.

Update with `brew upgrade --cask orb`. The cask is updated automatically by Orb's release workflow.
